# Cheese Slices - (Cheaha Dr, Oxford, AL 36203)

An interactive landmark website dedicated to **Cheese Slices -**, the 4.1★ Google Maps Tourist Attraction at the four-way stop sign on Cheaha Dr in Oxford, Alabama (`33.585785, -85.820824`).

- **Google Maps Pin:** https://maps.app.goo.gl/mee9EaQtmHFc8xZc7
- **Live Site:** https://cheeseslices.lol/ (hosted via GitHub Pages)

## Features

- **Interactive 4-Way Stop Sign Simulator:** Click anywhere on the `STOP` sign to slap American cheese slices onto it (or click a slice to peel it off).
- **Three Historical Era Presets:**
  - *Era I: Midnight Dozen* (Nighttime Headlight Mode with 12 slices)
  - *Era II: Lone Survivor & Remnant* (Daytime 1 intact slice + 1 charred remnant)
  - *Era III: No Cheese. Just Stop Sign.*
- **Sun-Bake / Age Button:** Watch slices weather over time.
- **Curated Archive & Verified Reviews:** Features quotes and telemetry from the public Google Maps listing, plus a local field-sighting guestbook and interactive map embed.
